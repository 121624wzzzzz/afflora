# 固定数据划分的重复检查

2026-09-14 对完整 22,780 条训练、1,000 条 dev、1,000 条 test 和 541 条 IFEval 做了只读复核。未修改或剔除任何样本。

三个 SFT 划分之间，record ID、完整对话、首轮用户提问、每个 assistant 回合的完整预测上下文，以及该上下文连同回答的交集均为 0。文本比较同时检查原始完整对话和合并连续空白后的内容。IFEval 提问与 SFT 任意用户回合的空白归一化精确交集也为 0。

任意单独用户回合存在重复：train/dev 共享 441 个不同提问，train/test 共享 431 个，dev/test 共享 125 个。这些重复回合没有相同的完整预测上下文，不能等同于重复的监督样本。训练集内部有重复的首轮问题及少量重复的上下文加回答；完整训练对话本身互不重复。

这是精确匹配诊断，未检查语义近重复，也不证明模型预训练阶段没有接触 IFEval。它支持当前数据划分在已检查层面没有跨划分重复监督样本，不支持更广泛的“无数据污染”主张。

机器可读计数、脚本和数据 SHA-256 见 [DATA_OVERLAP_AUDIT.json](DATA_OVERLAP_AUDIT.json)，复核程序见 [audit_data_overlap.py](audit_data_overlap.py)。
