# 动态结果报告误纳入冻结清单的处理

2026-09-15 01:45，结束前的清单检查发现 `chat/RESULTS.md` 被误纳入不可变输入清单。该文件由冻结的 `chat/summarize.py` 在每组完成后自动重写，训练、CE 和生成评测代码均不读取它。其他冻结条目的哈希全部匹配。

使用未修改的汇总代码、零完成实验和 `smoke` 状态，已重建出与清单内 SHA-256 **完全相同**的原始 `RESULTS.md`。原文、发现时的报告、原清单和相关代码均保存在 `report_manifest_audit/`。这不是方法、超参数、数据、模型或评测规则的变更。

原调度器会在所有实验完成后因这个动态输出的哈希变化而报错；保留该错误及日志。另行执行 `finalize_chat_audit.py`，只将这个明确的派生报告从不可变输入检查中排除。原清单与原实验代码保持不变，全部其他冻结文件、软件版本、模型文件实际 SHA-256、训练产物、52 份 CE 和 26 份生成评测继续接受检查。审计持有原调度锁，须在原调度器退出且全部任务完成后才能执行。

最终 `chat/FINAL_AUDIT.json` 会明确记录原审计失败原因、这一项例外、对应原始与最终报告哈希、另行执行的审计程序及其哈希。`passed` 表示这些注明范围的检查通过，不能描述为原清单每个条目均保持不变。最终统计仍由逐样本结果重算，并在 `FINAL_ANALYSIS.json` 中单独记录聚合校验。
