# 下游任务扩展：ANLI R1 与 WikiSQL

本实验在读取任何新任务模型输出前制定。目的：测试边界 A-LoRA 的叠加收益能否扩展到自然语言推断和查询语义解析。全部任务及正、负、零结果均保留，不以 Base 低分或 A-LoRA 涨分作为纳入条件。

## 数据与指标

- ANLI v1.0 官方 R1：仅使用 premise、hypothesis；reason、旧模型预测等字段绝不进入输入。官方 train 中固定抽取 2048 条，官方 dev/test 全量保留（各约 1000 条）。输入为英文三分类指令，A=entailment、B=neutral、C=contradiction。主指标为三个固定单 token 标签的条件概率 argmax 准确率，不加入 EOS 概率。补充全词表下一 token 是否直接为正确标签及标签概率质量，排除格式因素。训练仍为 label+原生 EOS 的 SFT。
- WikiSQL 固定 Git revision cffb423077756d04c1bac5bcd45167c86903fbcb。官方 train 固定抽取 2048 条、dev 256 条、test 1024 条。官方分表，核验表 ID 以及标准化输入重叠。输入只给问题和编号后的列名/类型，不提供答案、SQL 或表中示例值。输出官方查询结构 JSON：sel、agg、conds。主指标执行正确率，补充官方逻辑形式精确匹配、查询有效率、严格 JSON 合法率。执行过程与固定官方参考核对；非法/截断输出保留分母。此为固定小样本子集实验，不作为完整 WikiSQL 排行榜分数。
- 抽样通过稳定 ID 的 SHA256 排序，抽样 salt 固定为 downstream-transfer-20260917。在抽样前排除 train/dev 与更高优先级分区的重复输入（test > dev > train）；记录全部排除。ANLI 另排除训练池中出现在官方 dev/test 的前提段落，得到 6255 条候选，保证训练与评测前提不重叠；dev/test 本身共享部分前提，分别报告且不据 dev 调参。此项在数据审计后、任何模型运行前修订，原版本保存在 preflight_v1。不得根据模型结果换样本。若数据有结构/长度错误，先修正并记录，冻结数据后再运行模型。
- 两模型所有选中数据均不截断输入；token 长度在训练前审计。WikiSQL 最多生成 256 token（预先检查 gold 可容纳），贪心解码，无执行引导、无 gold 感知修复。ANLI 用同一固定标签编码，不使用标签随机排列或挑选有利映射。

## 模型与训练

- Qwen3-0.6B-Base、Qwen2.5-1.5B 官方 Base，复用已验证原始权重，重新检查所有 14 个模型/分词器文件 SHA256。不复用任何已训练 adapter。
- Base、普通内部 LoRA（hidden）、LoRA+A-LoRA（hidden_both）、严格等参数内部 LoRA（hidden_budget）。后三者各 5 个种子：7100–7104；Base 不重复计作多种子。
- 保持既有 r8/alpha16 内部 LoRA、r16/alpha128 输入输出边界层、固定 q/k 增秩的等参数对照。共享 r8 参数初始化和训练样本顺序配对核验，基础权重全程冻结。
- 所有任务和适配方案共同 LR=2e-4，2048 条、1 epoch、有效 batch32，microbatch4；AdamW beta=(0.9,0.999)、eps1e-8、WD0，梯度裁剪1，3%预热后余弦衰减。固定最后一步，无开发集选 checkpoint/选学习率。
- 冻结 Base BF16、adapter/优化器 FP32，训练 BF16 autocast；评测 FP32，TF32 关闭，SDPA。统一评测 batch16。训练只对答案+EOS求 token 平均损失，prompt/padding=-100。
- 每个 task/model 一次 2-step 冒烟，仅检查正确性，不依据分数筛任务；随后运行全部 60 次正式训练、4 个 Base。若实现错误需修改，保留失败记录并使全部相关对照应用同一修复。

## 统计与解释

四个 task/model × 两个对照（both−hidden、both−budget）共八项预定主比较。以五个配对种子差值报告均值、全部种子值和 Bonferroni 校正的双侧95% t区间；未校正区间仅作补充。题目/表簇重抽样区间以已经训练出的五个模型为条件，不替代种子变异。

ANLI 接近随机水平也保留，不因未学会任务而排除。WikiSQL 执行正确可能由结果碰巧相同造成，因此同时报告逻辑形式匹配与空结果比例。两个 Base 模型来自同一模型家族、数据公开且预训练暴露未知、训练预算和共同学习率固定；不声称最优调参下的普遍优越性。

## 复用与归档

先检查旧封存清单和所复用文件哈希，在新目录内修改。旧结果目录保持封存。新代码/数据/任务说明在模型运行前分别冻结哈希；结束后独立重评分、核验参数与原权重冻结、保存重载、初始化配对与训练顺序，生成完整文件清单。
