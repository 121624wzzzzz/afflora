# New tasks: fixed pre-output construction and evaluation

This phase is part of the 14-hour window in ../PLAN.md. Eight official pretrained Qwen Base models, three arms (ordinary H, budget H, H+E+U) each with three paired seeds, plus deterministic Base. The intended 160 formal jobs and 16 smoke jobs are a budget-limited queue; report actual complete blocks and all omissions. All results are exploratory and retained regardless of sign.

## TREC fine-grained classification

Author data and taxonomy: https://cogcomp.seas.upenn.edu/Data/QA/QC/ . Original train_5500.label is decoded as latin-1. Full official 500-question TREC_10 test is retained. Remove normalized test-overlap and duplicate questions from training; split internal dev256 from the remaining official train using deterministic per-class hash order and round-robin quotas, with at least one remaining training item per class. Then sample train2048 by deterministic class round-robin, retaining all 50 classes. Sampling and all removed IDs/counts are recorded in DATA_AND_REUSE_AUDIT.json; no output-based edits.

The prompt lists all 50 fine class labels and fixed taxonomy descriptions with codes00–49. It asks for the requested answer type, not an answer to the question. Train on the exact two-digit code plus native EOS. Primary evaluation is argmax of the exact joint likelihood of both code tokens, equal-length candidates, no length normalization or EOS term. This is classification, not free answer generation. Secondary: all-50-class macro-F1 (zero for absent undefined classes) and coarse-label accuracy. Candidate cache implementation is checked against independent complete prefix forwards on shortest/longest evaluated prompts for every checkpoint, with equal argmax and <2e-4 absolute log-probability error. Eval batch8, microbatch2, seeds9100–9102.

## SQuAD2 contextual QA with abstention

Official v2.0 train/dev and author evaluation script: https://rajpurkar.github.io/SQuAD-explorer/ . Data are CC BY-SA4.0; source URLs and exact downloaded hashes are in DATA_SOURCES.json. The public official dev supplies this experiment's held-out sample, not the hidden benchmark test. Internal dev comes from entire article groups in official training, selected by a fixed hash (one tenth of titles). Remove duplicated context/question pairs and any official-train context appearing in the held-out source. Train, internal dev and held-out have disjoint article titles and normalized contexts.

Pre-output eligibility: complete prompt <=768 tokens under the pinned Qwen2.5-1.5B tokenizer; every nonempty-normalized gold answer serialized as the output object plus EOS fits the 128-token generation cap. Every selected item is then checked under all eight tokenizers. No context, answer or question is truncated. This defines a short-context subset, not full SQuAD2. Deterministic hash sampling yields train2048, internal dev256 and held-out1024, with exactly half answerable and half unanswerable in each split. Gold answer_start offsets are validated against the original passage. The training target uses the first official nonempty-normalized answer, or empty string for unanswerable; evaluation retains all official answers.

Prompt: use only the passage, copy the shortest complete answer span, return a JSON object with exactly the string key answer, and use an empty string when no answer is supported. Primary is official-normalized multi-reference token F1; exact match, answerable-only F1/EM, unanswerable-only F1/EM, raw-empty answerability accuracy, extractiveness, schema validity, strict JSON, EOS and cap rates are separate. Parsing is gold-blind: a leading JSON object or a JSON code fence may be accepted, trailing text affects strictness, duplicate keys/non-string answers fail. Invalid JSON always receives zero, including on unanswerable items; it is never converted into a correct abstention. No confidence threshold is fit and no output repair or retry is used. All valid predictions are independently checked with the original author EM/F1 functions. A constant empty valid answer would score50 on the balanced overall measure, so answerable-only scores must accompany it. FP32 greedy generation, cap128, batch8, microbatch2, seeds10100–10102.

## Training and inference shared across methods

Train2048, one epoch64 steps, effective batch32, common LR2e-4, two warmup steps/cosine, AdamW(0.9,0.999), eps1e-8, weight_decay0, clip1. Frozen base BF16, trainables/moments FP32, BF16 train autocast. Answer+EOS token-mean loss with prompt/pad masked. FP32 evaluation, TF32 off, SDPA, native EOS151643, no chat template. Final checkpoint only. H r8/alpha16/dropout0.05 on q/k/v/o/up/down/gate; E/U r16/alpha128/dropout0, input bias only. Budget matching and model identity are inherited by verified copying from the core phase, with any rank-granularity excess explicitly reported.

Each run checks zero-residual equality, independent loss, parameter whitelist, frozen-base gradients/digests, actual adapter updates, FP32 optimizer state and exact save/reload. Two-step longest-sequence smoke tests have no performance gate. All raw output, candidate likelihoods, checkpoints and failures are retained. Test data never choose hyperparameters/checkpoints/seeds.

## Analysis boundary

For each of16 model/task conditions, compare H+E+U with H and budget H:32 planned contrasts, three paired seeds, df2. Show raw seed differences, mean/SD/direction counts, descriptive unadjusted95% seed-t and Bonferroni32 intervals; keep32 as denominator even if the time limit leaves some rows unfinished. Only complete common-seed three-arm blocks get paired summaries. No task was chosen using a new model score, but these public corpora may have been seen in pretraining. Small balanced subsets and common, untuned hyperparameters limit transfer claims. Do not infer universal benefit from a selected positive row or from high abstention/classification scores.
