# Core model and architecture matrix (pre-output freeze)

See ../PLAN.md and ../WINDOW.json for model coverage, priorities and the hard time budget. All eight official models are pretraining-only Qwen Base checkpoints. Model paths, revisions, tying and file hashes are in models.json / MODEL_IDENTITY_AUDIT.json.

Data are exact copies of the sealed model_scaling_20260917 CLUENER and WikiSQL datasets. CLUENER: 2048 train / 200 dev / 1343 held-out public-dev examples, microbatch 2, generation cap 512, evaluation batch 8 dev / 32 test. WikiSQL: 2048 train / 256 dev / 1024 held-out test examples, microbatch 4, generation cap 256, evaluation batch 16. Raw official tables, golds, prompts, parsing and scoring are unchanged. No truncation, response repair, output retries or task gating on accuracy.

Every fit: one epoch, effective batch 32, 64 steps, LR 2e-4, AdamW (0.9,0.999), eps 1e-8, weight decay 0, gradient clip 1, warmup ceil(0.03*steps) then cosine. Base weights BF16 and frozen, trainable parameters and optimizer moments FP32, BF16 autocast for training. Loss is answer-plus-native-EOS token mean with prompt/padding masked, scaled over the effective batch. FP32 greedy generation, TF32 disabled, SDPA, native EOS 151643, no chat template. Final checkpoint only. Existing pilot intermediate evaluation does not select a checkpoint and is disclosed in provenance.

H: r8, alpha16, dropout0.05 LoRA on q/k/v/o/up/down/gate projections. E and U: separate r16, alpha128, scale8, dropout0 hidden-dimensional residual affine maps. E has one hidden-size bias; U has no bias. E parameters=33*d, U=32*d, E+U=65*d. H+E/H+U include only the named boundary. E/U/E+U standalone include no internal LoRA. BUDGET_PLAN.json enumerates actual counts. Budget H expands one rank in a deterministic q/k subset while preserving the original rank-8 initialization and alpha/r=2. Rank granularity may cause an explicitly recorded small excess; do not call such rows exactly equal.

Arms are Base, H, budget H, H+E, H+U, H+E+U, E, U, E+U. Three paired seeds for breadth, five pre-specified seeds for the two untied models. Base is deterministic and evaluated once per task/model. Five-seed historical rows are not substituted for three-seed rows. Selected source checkpoints/output files are independently hashed; each reused response is decoded and rescored and each sample order must match torch.randperm at the exact new seed. No fitted checkpoint reuse for initialization.

Before each fit: zero-residual equivalence, independent shifted/masked loss equivalence, exact parameter whitelist, actual tied-weight pointer check. During fitting: original weight gradient absence, finite updates, FP32 optimizer states. After fitting: frozen-base digests, every requested adapter group changed, save/zero/reload exact loss, checkpoint hashes. Smoke runs are two steps and longest-sequence memory checks without a scored performance gate; all outputs are retained separately.

Primary: CLUENER span micro-F1 with malformed entities counted as false positives, and official WikiSQL execution accuracy. Secondary format, exact-content, text F1, LF and distinct-placeholder execution diagnostics remain separate. All official-valid SQL predictions are checked against the official engine during independent audit.

Exploratory planned contrast family: for each of 16 model/task conditions, H+E+U minus H and minus budget H; H+E minus H; H+U minus H; H+E+U minus H+E and minus H+U; E/U/E+U each minus Base; and E+U minus E and minus U. Total 176 planned contrasts for the common three-seed matrix. Report raw differences and both unadjusted descriptive 95% seed-t and Bonferroni-176 intervals (df=2), retaining this denominator even if time leaves conditions incomplete. Untied five-seed extension is reported separately using the same 176 denominator (df=4), without treating nested three/five-seed summaries as independent replications. No claim that a positive mean or uniformly positive signs alone satisfy corrected inference. No after-results seed expansion, tuning, subset selection or modified scoring.
