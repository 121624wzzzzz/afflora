# 本轮架构对照如何对应论文主张

本文件解释代码实际训练的对象。结果以 FINAL_INTERPRETATION_ZH.md 和冻结分析为准。

令词表输入矩阵为 W_E，输出矩阵为 W_U，隐藏维度为 d。输入查表后的列向量 x 使用 `x' = x + 8 B_E A_E x + b_E`；输出最后一层 hidden state h 使用 `h' = h + 8 B_U A_U h`，再送入原 lm_head。A 为 16×d，B 为 d×16。A 随机初始化、B 和输入 bias 为零，因此初始函数与 Base 完全一致。

E 有 33d 参数，U 有 32d 参数，双侧共有 65d。原 W_E、W_U 和所有 Transformer 参数一直冻结。H 是 q/k/v/o/up/down/gate 的 rank-8 LoRA。`core/modeling.py` 与 `new_tasks/modeling.py` 通过参数白名单、实际 tensor 指针和前后 digest 检查这些约束。

|问题|直接比较|能回答的范围|
|---|---|---|
|在常规内部LoRA上能否增加收益|H+E+U 对 H|相同数据、步数、LR下的完整方案增量|
|是否只因增加参数|H+E+U 对预算H|固定预算分配方案下的对照；不是所有内部rank分配的最优值|
|untied模型哪一侧有贡献|H+E 对 H；H+U 对 H|各自添加对应分支的效果，含其容量和优化设置|
|第二侧是否仍有价值|H+E+U 对 H+E；H+E+U 对 H+U|已有一侧时再加另一侧的增量|
|只训练边界能否适配|E/U/E+U 各对 Base|不训练H或原始权重时，边界模块的适配能力|
|只训练边界是否低预算最优|本轮没有该完整对照|还缺同预算standalone内部LoRA方案，不能据此宣称最优|

Qwen2.5-7B 和 Qwen3-8B 的原输入、输出权重 untied，其余六个模型 tied。本轮即使原始权重 tied，也分别训练独立 E/U 分支；不能声称它们最终仍能合成同一个共享矩阵。Untied 时两侧可以各自吸收进各自权重，数学上不存在必须共享更新的约束。是否导出合并以及有限精度误差不是本轮的性能实验结论。

合并矩阵的原始差异不等同于 softmax 概率差异：如果每个词表行相差同一个向量，只会给所有logits增加相同标量。因此CPU矩阵审计还记录去除行均值后的差异及抽取词表行上的相对logit差异；它仍然只是采样数值检查，不是全词表或端到端生成评测。

双侧得分最高不自动等于“超加性协同”。主分析固定比较双侧与两单侧。另附事后描述性差分 `HEU − HE − HU + H`，只反映当前指标尺度上的算术交互，不当作机制证明。

八个模型构成两个系列的覆盖，但尺寸、层数、宽度、词表绑定和预训练同时变化；规模图不能孤立证明参数规模的因果作用。所有适配方案共用一个训练预算与LR，本轮回答的是这一固定可复现设置下是否观察到增量，不代表各方法经过充分调参后的上界。
