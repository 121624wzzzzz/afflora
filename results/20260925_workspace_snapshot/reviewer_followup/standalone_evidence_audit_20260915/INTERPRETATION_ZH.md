# A-LoRA 独立使用：目前存在什么证据

独立使用时的可训练参数节省成立；修复流程后的三种子实验也显示明确的留出 SFT 测试 CE 改善。实际任务准确率、生成质量和同预算竞争优势尚未得到充分确认。叠加实验的阴性结果不能推出独立 A-LoRA 无效。

## 已核对的独立适配结果

数据是修复多轮顺序、原生 chat template、assistant-only loss 和精确上下文跨划分重叠后的 SFT 数据，22,780 train / 1,000 dev / 1,000 test。这里的测试集在此前研究中已经被查看，属于固定数据上的受控复现，不是首次使用的新测试集。模型为 Base 版本。

| 模型 | 未适配 CE | 仅输入 A-LoRA：参数 / CE | 仅输出 A-LoRA：参数 / CE |
|---|---:|---:|---:|
| Qwen3-0.6B-Base | 1.875729 | 33,792 / 1.477954 | 32,768 / 1.548638 |
| Qwen2.5-7B-Base | 1.657705 | 118,272 / 1.266595 | 114,688 / 1.368168 |

适配后数字是 seeds 42/43/44 的均值；两种 placement 在两模型全部种子上都优于相同未适配模型，输入端均优于输出端。输入端多一个 d 维 bias，因此输入/输出不是完全等参数对照。

输入端相对未适配模型的 CE 差：Qwen3 −0.397776，三种子的名义 95% t 区间 [−0.399574, −0.395977]；Qwen2.5 −0.391110，区间 [−0.393798, −0.388421]。这是已训练种子在固定测试集上的损失证据，不是独立任务准确率收益。

原报告：[placement × capacity](../placement_capacity_corrected_20260911/RESULTS.md)。

## 参数优势与参数效率应分开

对同一词表矩阵、同 rank r，带输入 bias 的 A-LoRA 参数量为 2dr+d；无额外 bias 的 Vocab LoRA 为 r(V+d)。因此参数量不随词表大小 V 增长这一性质是确定的。

例如 Qwen3 的单输入矩阵 rank 16：A-LoRA 为 33,792 参数；普通 Vocab LoRA 的公式计数为 2,447,360，约 72.4 倍。Qwen2.5-7B 的对应比值约 21.1 倍。这是同 rank 的参数量比较，不能解释成已达到同样效果时也节省同样倍数，更不能推广为训练时间或整模型显存按同一比例下降。

修复后的独立 placement 矩阵没有 Vocab LoRA 或同预算内部 LoRA，因此尚不足以确认独立 A-LoRA 的同预算优势。其内部 LoRA r1 对照的参数量更大、CE 也更低：Qwen3 为 630,784 参数 / CE 1.283851，Qwen2.5 为 2,523,136 / 1.036201。它们是预算—效果曲线上的其他点，不能直接把参数差或分数差归因于方法优劣。

论文 06_results.tex 中旧的 A-LoRA/Vocab LoRA 与单层 LoRA 表格早于 corrected SFT 流程，不能直接当成这一修复协议下已经确认的同预算结果。应在一致协议下复现再决定保留哪些比较。

## 实际任务证据

修复后的本组独立 checkpoint 只报告 SFT CE，没有对应的系统任务准确率/生成评测。

历史上存在纯输出 A-LoRA 的 Llama-3.1-8B 数学任务试验：无约束版本相对 frozen base 在 MATH 上 +3.2232 pp、GSM8K 上 −12.7369 pp；约束版本也是一正一负。它们只有 seed 42，且约束选择使用过这些 benchmark 的相关结果，只能作为探索性记录。本次未重新执行该历史实验的生成或评分，不能把它当成新的确认。

来源：[PURE_ALORA_ENERGY_RESULTS.md](../affine_energy/PURE_ALORA_ENERGY_RESULTS.md)、[选择规则](../affine_energy/PURE_ALORA_SELECTION.md)。

因此，“独立适配能学习有用的 token 概率变化”有明确证据；“独立使用能稳定提高实际任务效果，并且同预算胜过其他方法”是待验证的问题。

## 最值得补的实验

论文可以把独立小预算适配作为待验证的主要方向，但不能把叠加失败之后选出的新方向视为已经完成确认。

建议建立可训练参数量—实际任务表现曲线，所有方法冻结同一基座、完全不含额外全层内部 LoRA：

- A-LoRA input-only、output-only、bilateral 分开报告。
- 对照包含未适配模型、同预算分散到多个内部层的稀疏 LoRA、prompt tuning，以及可实现预算下的 Vocab LoRA。避免只选一个表现较弱的单层内部对照。
- 参数预算覆盖约 32k、64k、128k、256k，按各模型实际整数 rank/层数/提示长度记录精确参数与差额。普通 Vocab LoRA 的 rank 1 有最低参数门槛，小于门槛的格子标为不可实现；不要假装所有预算都能精确匹配。
- 至少两个任务、两个模型；训练数据与任务匹配，对称分配验证集调参预算，冻结方案后用新种子确认。将任务准确率或 EM/F1 设为主要指标，CE 与格式有效率为支持指标。
- 当前已检查的测试集用于诊断，最终主张使用另留出的、没有参与选择的测试数据。报告全部预定任务的正负结果。

本报告只完成旧证据审计与方案整理，没有启动新训练。若同预算下获得一致优势，才能形成独立参数效率主张；若只有相对 frozen base 的 CE 改善，论文主张就应停留在这个范围。
