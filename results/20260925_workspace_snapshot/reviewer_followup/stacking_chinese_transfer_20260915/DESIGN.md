# 中文任务迁移评测：边界适配叠加后的答案收益

2026-09-15，在新基准结果产生前固定。范围：已有中文 SFT adapters 的迁移评测，没有任务内重新训练。保留全部 24 个训练端点（2 模型 × none/output/both/hidden_budget × seeds 42/43/44）和 2 个未微调参考。none 指 hidden LoRA，reference 才是未微调模型。主要对比：both−none 和 both−hidden_budget；不得只选择一个对照或一个种子报告。

数据来自作者仓库固定 Git commit，下载内容与上游 Git blob SHA-1 一致，另存 SHA-256。CMRC 使用 squad-style public dev 全部 3,219 题作为本轮最终评测，不称为官方隐藏 test；C3 使用 d/m test 全部 3,892 题。训练来源的样本仅用于程序烟测，CMRC 首 8 题、C3 d/m 各首 4 题。不按结果挑提示、任务或截断子集。上下文、问题的精确重叠检查保留，不宣称排除预训练污染。C3 训练集两题有重复正确选项，原样保留正确索引集合；本轮 C3 test 没有该歧义。

提示全文固定在 common.py。使用各模型原生 user-only no-thinking chat template，不加 few-shot 示例。答案条件概率将原生提示 token 与单独编码的答案 token 拼接；仅评分答案内容，不含提供的空 thinking 前缀、EOS、解释或选项编号。保存此明确 token 拼接定义，不将其混同于任意完整字符串的联合分词。

CMRC：greedy 自回归生成，max_new_tokens=256，repetition_penalty=1，原模型 EOS 加原生 im_end 停止。批量最多 16 条，按源顺序、padding 后最多 8,192 个 prompt token 组成批次，单条长于批量预算时单独运行。上下文含最大输出不超过 8,192，超限明确报错，不静默截断。记录全部输出 token、停止位置与截断率。主要分数为 (EM+F1)/2，另报 EM/F1；评分完全保留官方 v5-special 的标点处理、混合分词和最长公共连续片段算法，仅移除 Python 2 专属语法。原脚本及转换程序均保留。不得换成通用 SQuAD F1 或按答案内容清洗输出。使用当前已核验 NLTK 依赖和数据。

CMRC 的辅助指标为所有参考答案的 answer-only CE 与 top-1；每题先等权平均参考答案，再等权平均题目。它与先前按 token 加权的聊天 CE 口径不同，不直接混算。

C3：按候选答案的平均 token log probability 取最高分，报 accuracy、正确选项与最强错误选项的分差、正确答案 CE/top-1。总 log probability 取最高分作为预先声明的敏感性分析；两个口径均完整报告。保留原始候选顺序，相同分数取最早索引；d/m 子集与合并结果都报告。似然选项准确率属于答案排序证据，不单独称为自由生成收益。

Likelihood 前向：eval 模式、沿用旧评测模型加载及权重 dtype、无新增 autocast；右 padding，batch 至多 16、padding 后至多 4,096 token，单条超过批量预算时单独处理，单条总上下文上限 8,192。仅抽取答案位置 logits，再用连续存储 FP32 CE；以 FP64 CE 和显式 logsumexp 在烟测上核验，逐 token 容差 5e-6。greedy 生成采用左 padding。同一个模型的所有实验臂共享同一数据、批次划分和解码设置。数值及批次实现固定后不按分数调整。

复用 gate：只读核实旧清单输入与软件版本、基础模型完整 SHA-256、adapter/config/run_args、旧训练完成标记和生成元数据中的 checkpoint 身份。沿用并明确记录旧清单中派生 RESULTS.md 的唯一例外，不宣称旧清单每项都未变化。每个端点在新任务前独立重载并重现固定前 8 条旧 test CE，逐条 mean CE 最大误差须 ≤1e-8；不通过就停止该端点。八种模型/实验臂以及两个未微调参考先在训练样本上完成烟测，再冻结正式评测清单。

推断计划：两项任务、两个模型、两个主要对比共 8 个主要效应。以固定评测集上的三种子配对效应给出均值及名义 t 区间，同时给出以这三组拟合模型为条件的配对篇章簇 bootstrap 区间（10,000 次，固定随机种子 20260915）。CMRC 使用 context ID，C3 使用规范化材料文本哈希作为簇，多题共享篇章须一起重采样。分别报告两种不确定性；另给 8 重比较 Bonferroni 同时区间，不能把名义 95% 区间当成已控制全部多重比较。辅助指标与子集结果标明探索性。保存全部逐题、逐种子结果及输入/输出哈希。

本轮能判断当前 adapter 的中文问答和阅读理解迁移。即使仍无收益，也不据此证明所有任务内训练都无增益；也不得继续换任务直到正结果才报告。既有 IFEval 的正负结果继续保留。CLUENER 与 CMRC 的任务内训练属于后续独立实验，不包含在本轮数据或结果中。
