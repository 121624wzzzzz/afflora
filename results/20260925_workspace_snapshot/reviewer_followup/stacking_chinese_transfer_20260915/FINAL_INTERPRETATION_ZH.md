# 中文迁移评测结论：均值增量存在，但跨种子稳定性有限

2026-09-15，26 个端点、52 项任务评测全部完成并通过最终审计。两个模型、四个训练臂、三个种子，以及两个未做本轮 SFT 的聊天模型参考，均完整保留。CMRC 使用 public dev 3,219 题，C3 使用 test 3,892 题。这轮只测已有中文通用对话 SFT adapters 的迁移，没有在新任务上训练。

**换成中文任务后，CMRC 出现正向平均增量，但训练种子波动仍然明显。不能将先前 IFEval 不稳定完全归因于英文，也不能据此声称跨任务、跨种子稳定生成收益已建立。**

| 任务 / 模型 | both−hidden，百分点 | both−等预算，百分点 | 三种子方向概况 |
| --- | ---: | ---: | --- |
| CMRC / Qwen3-0.6B | +0.3745 | +0.0669 | seed 42 正向；seed 43 反向；seed 44 接近零 |
| CMRC / Qwen2.5-1.5B | +0.8733 | +0.7620 | seeds 42、43 正向；seed 44 小幅反向 |
| C3 / Qwen3-0.6B | +0.2998 | +0.3169 | 小幅增量；相对 hidden 的种子及篇章区间包含零 |
| C3 / Qwen2.5-1.5B | -0.0856 | -0.0428 | 均值接近零，未建立额外收益 |

CMRC 指标为固定的 (EM+F1)/2，自回归生成后使用官方评分算法；C3 是候选答案平均 token 条件似然的选择准确率，不是自由生成。总 log probability 的 C3 敏感性口径也完整保留，未按正负选择口径。

**种子与篇章不确定性必须区分。** CMRC 的 Qwen2.5 两个对照，其条件于这三个已拟合模型的篇章簇 bootstrap 区间均为正；8 重比较校正后的区间分别约 [0.4591, 1.2835]、[0.3675, 1.1480] 个百分点。但跨三次训练的名义 95% t 区间分别为 [-1.7580, 3.5045]、[-1.4511, 2.9751]，都包含零。题目层面的精度不能替代训练种子的可重复性。

Qwen3 在 C3 上相对等预算对照的名义种子区间和名义篇章区间均略高于零，但相对普通 hidden 的区间仍含零；篇章区间的多重比较校正后也不能据此宣布整个主对比家族成立。完整区间见 [RESULTS.json](RESULTS.json) 和 [汇总表](RESULTS.md)。

CMRC 的逐种子增量如下，可直接看到初始正向信号如何在重复实验中变化：

| 模型 / 对照 | seed 42 | seed 43 | seed 44 |
| --- | ---: | ---: | ---: |
| Qwen3 / hidden | +1.6386 | -0.5220 | +0.0067 |
| Qwen3 / 等预算 | +1.4465 | -1.1619 | -0.0839 |
| Qwen2.5 / hidden | +1.9365 | +0.8653 | -0.1819 |
| Qwen2.5 / 等预算 | +1.5575 | +0.9291 | -0.2006 |

绝对能力也有模型差异。Qwen3 的未微调参考 CMRC 为 45.5295，hidden 为 46.2174，both 为 46.5919；Qwen2.5 的参考为 47.0165，hidden 为 38.0203，both 为 38.8936。因此 1.5B 上相对 hidden 的增量不能写成已经超过原始聊天模型。

**输出形式是值得继续控制的因素，但不是已确认的全部原因。** 事后字符串诊断中，Qwen3 的 151 次 EM 改善有 123 次，Qwen2.5 的 184 次改善有 167 次，原 hidden 回答已经包含至少一个规范化参考答案字符串。该现象与“原回答多说了内容，生成更贴近目标答案形式后获得 EM”相容。字符串包含也可能出现在否定、无关提及或错误上下文中，因此不能称为语义正确率或将这些样本直接分类为纯风格收益。该诊断在看过 seed 42 后设计，明确属于探索性分析，未替换官方指标，见 [GENERATION_DIAGNOSTICS.json](GENERATION_DIAGNOSTICS.json)。

新任务上的答案 CE 本身也并非所有种子一致改善。例如 Qwen3 相对 hidden，三个种子在 3,219 题中 CE 降低的数量为 2,447、1,513、1,573；Qwen2.5 为 2,654、2,278、1,515。这与旧中文对话 test 上广泛且一致的 CE 改善不同，进一步说明“同语言”不等于“同任务/同分布”。

复用与实现检查：全部基础权重完整 SHA-256、旧源码/数据依赖、adapter/config/run_args 与旧完成标记核实；26 个端点各重现 8 条旧 test CE，共 208 条，最大误差 0。新答案概率 FP32 CE 在烟测对 FP64 与显式 logsumexp 核验通过。CMRC 评分为保留算法的 Python 3 兼容版本，另用官方整集评分入口重算全部 26 组通过。6 个选定端点的前四个原始 CMRC 批次共 280 条独立重生成，token、文本、分数逐项一致。旧清单派生 RESULTS.md 的唯一例外仍明确保留；本轮没有新的不可变输入例外。[最终审计](FINAL_AUDIT.json)、[重生成审计](GENERATION_REPLAY_AUDIT.json)

上述结果不否定已建立的中文对话 CE 叠加收益，但不足以把主张扩大为普遍稳定的生成收益。更直接的下一项实验已单独建立为 [CMRC 任务内训练](../stacking_cmrc_task_sft_20260915/DESIGN.md)：从相同原始模型新训练四个实验臂，让训练目标和最终短答案指标一致。它是明确的顺序补充，保留本轮全部正负结果；不能把已看过的 public dev 称为全新未触碰测试集。
