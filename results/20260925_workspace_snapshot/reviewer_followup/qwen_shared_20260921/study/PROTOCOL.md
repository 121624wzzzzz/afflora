# Shared E/U rank ablation, 2026-09-21
Four Base models: Qwen2.5-1.5B (tied), Qwen3-0.6B (tied), Qwen2.5-7B (untied), Qwen3-8B (untied).
Two tasks: CLUENER and WikiSQL. Three paired seeds, 6100..6102 and 7100..7102. 48 new formal fits, 16 technical smoke probes.
All new arms retain hidden LoRA rank8/alpha16/dropout0.05. One shared boundary map has rank16/alpha128 or rank32/alpha256, scale8/dropout0, one input bias. Output uses the transpose and the common logit shift implied by that bias. Parameters are registered and optimized once. Tied models preserve effective tying algebraically; untied models share only the transform, not base weights.
Extra parameters: independent r16 E+U =65d; shared r16 =33d; shared r32=65d exactly. Shared r16 is not exactly half because one bias remains. Historical hidden_budget excess512 for Qwen2.5-7B must be disclosed, not called strict equality. Comparison with independent E+U is exact at shared rank32.
Existing frozen data, tokenization, native EOS, 2048 training examples, 64 optimizer steps, batch32, LR2e-4, warmup/cosine, AdamW, clipping, base precision and greedy evaluation are unchanged. No test-based rank/LR selection. Evaluate and retain both ranks on every model/task/seed.
Historical H, hidden-budget, independent E+U, Base and untied single-side arms are reused only after hash/identity/re-tokenization/re-scoring checks. They are not new independent replications. Single-side comparisons have unequal boundary budgets; report counts.
Primary comparisons per condition: shared16 vs independent16/16 (budget efficiency), shared32 vs independent16/16 (same-budget constraint), shared32 vs shared16 (rank+budget change), each vs H and hidden_budget. Report all paired seed deltas and means, including negatives. Three seeds are descriptive evidence, not proof of stable superiority. Shared optimization couples gradients; constant alpha/rank does not equalize all gradient statistics.
Technical gates: exact zero residual; tied base pointer; unique parameter count; shared transpose algebra and gradient sum; only adapters train; frozen base unchanged; FP32 optimizer; saved adapter reload exact; independent response scoring including official SQL execution. Smoke must pass independently for each model/task/rank before formal jobs for that configuration.
Stage reporting after each audited seed group; never select or stop a configuration based on the sign of its test gain.
