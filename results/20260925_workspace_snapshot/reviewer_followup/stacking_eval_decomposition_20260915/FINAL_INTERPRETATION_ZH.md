# 效果评测深入复核：需要更新口径，也出现了新的概率层收益证据

完成于 2026-09-15T14:20:17+08:00。24 个 CMRC 任务内训练 checkpoint 全部独立重载；两模型、四臂、三个种子均保留。没有新增训练、替换基准或覆盖旧结果。

**评测需要更新。关键发现是：答案长度权重会改变 CE 的方向；内部验证集的改善不是仅由结束符贡献；两个模型的完整参考答案集合平均概率均有增量，贪心生成的跨模型稳定收益仍未建立。** 这些发现使“增量体现在哪里”比上一轮更清楚，也要求细化上一轮对 CE 与生成不一致的解释。

Qwen3 的 token 等权内容 CE 在三个种子中对两个对照均改善；每题等权口径在 seed43 却为反向。Qwen2.5 相对 hidden 的宏平均 CE 变差，而 token 加权均值略有改善；相对等预算的 token CE 则接近零且种子方向不一致。原 CE 数字并未算错，不能把不同分母下的结果直接当成同一量比较。

Qwen3 的公开集内容 micro CE 三种子方向虽一致，名义种子区间仍包含零。这里的方向复现不等于已完成确认性统计证明。旧生成四个主要比较的种子区间仍全部包含零；新增指标没有改写该结果。

四个对比中，1–4 token 短答案的 CE 均值都变差，其余三个桶的均值均改善。短答案包含 3,848/9,657 个参考，按题目等权时影响更大。已逐对比验证 `Δmicro−Δmacro = Cov(length, ΔCE)/mean(length)` 的恒等式。

此外，internal dev 参考答案平均 14.228 个内容 token，public dev 平均 8.197 个；原内部 CE 与公开答案 CE 还混合了划分、长度与监督范围差异。该事实描述了分布差别，尚未因果证明所有泛化差异由长度造成。

两个模型、三个种子中，双边叠加相对两个对照的内部验证内容 micro CE 都改善；不含 EOS 的结果仍成立。均值分解中约 88%–97% 的净内部验证 CE 改善来自内容部分，不能归为仅学会正确停止。该百分比是上述 NLL 记账分解，不能解释成因果机制贡献。

**公开集的答案起点与延续可以反向。** Qwen2.5 的首 token NLL 贡献在两个对照的三个种子中都变差；后续内容的平均贡献改善。首 token top-1 平均相对 hidden / 等预算分别变化约 −0.176 / −0.183 pp。Qwen3 首 token top-1 均值则为 +0.286 / +0.228 pp。对应种子区间在 JSON 完整保留，这些诊断不能被选为新主比较。它们说明“沿着 gold 前缀把后续概率建模得更好”与“从问题出发首先选中哪个答案”应分别检查。

**新增的完整参考集合概率。** 对每题去重后的参考字符串集合 Y，计算 `sum_y p(y, im_end | prompt)` 及其负对数。不同完整字符串在显式 EOS 后是互斥事件；不能直接对可能相互包含的答案前缀概率求和。这个量只覆盖给定字符串，不覆盖所有同义表达或官方规范化等价答案，也不等于 greedy EM。

12 个模型/种子/对照配对的完整集合概率均提高，集合 NLL 也均降低。Qwen2.5 集合 NLL 的名义种子区间仍含零；概率均值的四个名义区间为正，也不能在本次大量探索性指标中直接宣布新的确认性显著发现。所有 168 个诊断对比保留，没有挑选种子；这些对比之间高度相关，12 个同方向配对不是 12 次独立伯努利试验。

**重复参考与数值敏感性也检查了。** 最初独立检查要求相同参考字符串的概率逐位相等，实际失败：同一输入 token 序列在原始不同批次下存在数值差异。例如 Qwen3 hidden seed42 的 DEV_6_QUERY_0，同一“足球运动员”的内容 NLL 为 1.6429258 与 1.7488655；差异在旧概率与新逐项重现中都存在。具体 kernel 原因未进一步定位，不应把该现象叫作随机采样。

新增集合指标预先使用每个重复字符串的首次值；另独立用 FP64 的 exp/sum/log 检查 logsumexp 聚合、参考去重、概率范围和重复值取法。在每题对双边取已观察到的最小概率、对照取最大概率这一保守取法下，12 个配对的平均增益仍均为正。下面列出每个模型/对照跨三种子的最小保守增量：

| 模型 / 对照 | 三种子中最小的保守概率增量，pp |
| --- | ---: |
| Qwen3-0.6B / none | +0.2535 |
| Qwen3-0.6B / hidden_budget | +0.2323 |
| Qwen2.5-1.5B / none | +0.3848 |
| Qwen2.5-1.5B / hidden_budget | +0.2909 |

该包络只验证“对已观察到的重复概率选择哪一个”不会改变平均方向，不是对任意批次、FP32 全精度或所有数值误差的上界。单题集合概率范围最大约 0.0822，平均范围约 0.000813，不能把单题差异一概描述为可忽略。后续正式评测应对唯一 prompt/answer token 序列计算一次并缓存，固定精度与批次规则。全部首次失败与数值敏感性记录保留在 protocol_history/ 和 ANSWER_SET_CHECK.json。

**此次应该怎样更新结论。** 上一轮“稳定生成收益尚未建立”的判断仍保留；关于“新任务答案 CE 不一致”的说明需要加上权重限定。更具体的经验结论是：在本次两个 CMRC 任务适配模型中，叠加对正确完整参考答案的概率分配出现了重复的平均增量；内容 token 的变化依赖答案长度和预测位置，且未稳定转化为贪心生成增益。

这比只强调 CE 降低更接近任务目标，也比继续换基准寻找正分更能明确方法的适用边界。仍需独立确认，不能凭本次事后分解推出普遍生成收益、输入/输出位置反转或 tying 的因果机制。

**评测 v2 已落实的材料。** [EVALUATION_V2.md](EVALUATION_V2.md) 给出正式报告规范、公式、缓存与复用规则：建模指标并列 micro/macro；内容与 EOS 拆开；完整答案集合概率/NLL 作为补充；官方 EM/F1 各自列出；保持 hidden 和等参数两个对照以及全部种子。旧 AVG 作为上一轮冻结汇总继续保留，不按新结果重选主指标。
