## 模型与复用

采用官方预训练 Base：3B 固定 revision `3aab1f1954e9cc14eb9509a215f9e5ca08227a9b`，7B 固定 revision `d149729398750b98c0af14eb82c78cfe92750796`。六个权重分片分别与官方 LFS SHA256 对齐；配置和分词器文件与固定 revision 的 git blob 对齐。所有运行使用独立的 `verified_models/`，未覆盖原缓存。原缓存配置有额外字段，本轮使用已核验的官方配置。

3B 原生共享 embedding / lm_head 权重，7B 不共享；维度、深度等也随型号变化。它们属于同系列的实际模型尺寸扩展，不能据此单独识别“参数数量”或“权重绑定”造成的因果作用。两个边界适配器在共享和非共享模型中都独立放置；不因此声称可无条件合并成一张共享词表矩阵。

训练数据、提示、目标、原始数据库、官方 SQL 运行时代码和旧评分器先按封存 manifest 逐文件核验，再复制。历史 1.5B 的 32 组 Base / 适配器测试结果共 37,872 条输出重新解码、评分；旧分词记录和官方模型文件也复核。它们仅用于历史曲线锚点。新模型不加载旧适配器；每次训练从各自的官方 Base 和新初始化开始。

## 对照和训练预算

|模型|普通 LoRA|预算 LoRA|LoRA + A-LoRA|预算对照与叠加差额|
|---|---:|---:|---:|---:|
|3B|14,966,784|15,099,904|15,099,904|0|
|7B|20,185,088|20,418,560|20,418,048|+512|

3B 为严格等参数。7B 普通线性投影每增加一个秩的参数成本均为 1,024 的倍数，而固定 A-LoRA 定义需要 232,960 个额外参数，无法用整秩普通 LoRA 精确凑齐。因此保留 A-LoRA 架构，在控制组多给 512 个参数（约占叠加组可训练参数的 0.00251%）；不得写作严格等参数。预算对照沿用此前算法，在 q/k 投影分配额外秩，保持 alpha/r=2。它检验这一个额外秩分配方案，不穷尽其他分配策略。

普通 LoRA 覆盖全部层的 q/k/v/o/up/down/gate，r=8、alpha=16、dropout=0.05。A-LoRA 在输入和输出边界各 r=16、alpha=128、dropout=0，仅输入侧有 bias。原模型所有参数冻结；训练时原权重 BF16、可训练权重和优化器状态 FP32，BF16 autocast。逐次检查原权重哈希、梯度和优化器白名单，以及保存再加载的一致性。

每任务 2,048 条训练，一轮 64 次更新，有效批量 32，学习率 2e-4，2 步 warmup 后 cosine；AdamW betas=(0.9,0.999)、eps=1e-8、weight decay=0、梯度裁剪 1。CLUENER microbatch=2，WikiSQL=4，与各自历史实验相同。损失按真实答案 token 总数归一化，包含原生 EOS，屏蔽提示和 padding。无截断、无 ChatML、无按尺寸重新调参、无中间检查点筛选。共享内部 r8 初始化在三组之间配对；同种子的样本顺序与历史 1.5B 完全一致。

四个两步短程检查只检查数值、范围、保存恢复、最长训练批次内存和完整评测批量。它们没有得分门槛，不参与正式效果均值。

## 评测与统计

同提示 Base 是每模型 / 任务单次确定性评测，适配器是五个配对种子。CLUENER 使用 1,343 条公开有标签 dev 作为固定保留集；WikiSQL 使用之前固定的 1,024 条官方 test 抽样。这些不是完整新排行榜或完全未暴露的评测数据。预训练污染程度未知。

评测转 FP32、关闭 TF32、SDPA、greedy，无修复、重排或重试。CLUENER 最大 512 新 token，dev 批量 8、test 32；WikiSQL 最大 256，批量 16。原生 EOS 为 151643。保存原始 token、解码文本、EOS 和达到上限标记。基座提示敏感性和输出格式学习会影响零样本分数；低 Base 分不能解释为模型没有相关知识。

CLUENER 主指标为原始跨度 micro-F1。输出的 type/text/occurrence 按原文恢复跨度，非法条目计假阳性；辅助报告文本 F1、整句正确率和格式。WikiSQL 主指标与官方 query 执行一致，并用官方执行器逐条核对有效预测；逻辑形式匹配、查询有效率和严格 JSON 分列。官方对重复条件列复用参数占位符的行为保留，独立占位符版本另作诊断；执行相同并不保证查询语义普遍等价。

正式统计族固定为 2 个新尺寸 × 2 任务 × 2 对照，共 8 个叠加差值。每项用五个配对训练种子的差值，Student-t、df=4、Bonferroni-8 双侧同时 95% 区间。一个任务 / 尺寸只有同时超过两个对照、两个区间下界都高于零，才记作通过本轮预定标准。历史 1.5B 不合入该统计族；跨尺寸交互只描述，不新增事后显著性检验。各轮统计族分别解释，不视作对全部前期探索的整体校正。

区间条件于这一批固定测试题，反映训练种子变异。五种子不保证方差估计稳定；跨零不等于证明无效。共同超参数保证一致预算，但未证明任一方法已经充分调优。结论限定于当前小数据、单轮任务适配，不自动外推通用指令能力、任意模型家族或完整后训练流程。

本轮比较的是固定的完整适配方案。边界与内部LoRA的作用空间、alpha/r缩放和dropout设置不同；参数匹配本身不能把这些因素与放置位置逐一因果分离。结果可以支持该配置下相对普通/预算LoRA的额外收益，不足以单独断言收益来自某一个架构机制，也未排除更充分的内部LoRA调参取得同等效果。

## 补充分析的地位

`content_diagnostics.py` 只读已审计输出，生成长度、停止、NER precision/recall 和分类别结果，以及双方格式有效的子集比较。WikiSQL 按两组查询是否有效分层，净正确数可相加回主指标；NER 子集 F1 不可相加，且条件于模型输出，不能作因果分解。无法归类的非法实体仍计入总体主指标，不硬分配给某一实体类别。

`QUALITATIVE_PANEL.md` 固定取各模型 / 任务第一个种子，按原测试顺序分别展示最先两条叠加胜例和败例（若存在）。这些例子仅解释输出差异，不用于选配置、估计总体质量或替代全量统计。所有辅助指标与图表都是描述性，不扩大主统计族的确认性结论。
