# 从 Base 出发的单侧 A-LoRA 下游适配

**本轮结论：从预训练 Base 出发，只训练输入侧 A-LoRA，在本次 SciQ 主评测上获得了可重复的小幅准确率收益；输出侧没有获得可靠的主指标增益。** Qwen3/Qwen2.5 输入侧分别提高1.58/1.90个百分点，五个种子全部为正，校正种子区间与名义题目区间均在0以上。其中 Qwen2.5 的校正下界仅为+0.067个百分点，Qwen3 的题目区间下界为+0.180个百分点，应保留小效应和有限题集的解释边界。

输出侧主评测分别为−0.04/−0.38个百分点，两类区间均包含0；四种选项轮换平均则都有约+0.43个百分点的点估计收益，属于预定的支持分析，不能替换原始顺序主指标或据此宣称普遍有效/严格无效。更大预算的内部 LoRA 绝对准确率更高。

用 Base 作为“从预训练起点进行监督适配”的主要研究对照是合适的。本轮支持的主张应限定为单侧输入边界的小参数任务适配；完整通用后训练、跨任务迁移、同预算优势和叠加收益仍是不同问题。

![内容准确率与不确定性](figures/base_content_effects.png)

本轮直接使用官方预训练 Base checkpoint。A-LoRA 两个实验臂每次只训练输入或输出边界的一处适配器；另设独立的常规内部 LoRA r8 对照。所有原始权重均冻结，不复用已经训练的 adapter。

研究问题是科学选择题上的监督任务适配，不是完整通用指令后训练、RLHF 或跨任务能力保持。两模型分别用三个学习率做验证集选择，再用五个新种子确认。当前 SciQ 测试集在之前研究中已经查看过。

## 更大预算对照

内部 LoRA 与 A-LoRA 从同一 Base 出发，使用相同数据、训练步数、学习率搜索次数和确认种子。它在模型内部的多处投影上训练更多参数，因此仅作为较大预算性能参照，不是同参数预算方法优劣检验。

- Qwen3-0.6B-Base：内部 LoRA 参数 5,046,272，选项准确率 89.579%。输入/输出 A-LoRA 与其相差 -2.926 / -4.549 pp。
- Qwen2.5-1.5B (Base)：内部 LoRA 参数 9,232,384，选项准确率 92.305%。输入/输出 A-LoRA 与其相差 -1.222 / -3.507 pp。

## Base 与已经后训练的 checkpoint

以下复用上一轮封存的 post-trained 起点结果，仅提供背景。系列/规模、问题、训练步数和学习率搜索预算相同，但本轮 Base 使用文本补全与原生 EOS，上一轮使用 ChatML 与 im_end。因此模型起点和输入/停止协议同时不同，不能把差异单独归因于 Base/Instruct，也不能进行配对显著性推断。

|---|---:|---:|---:|---:|---:|---:|

## 纠正的 Base 监督协议

直接搬用 ChatML 的初始尝试在验证调参阶段停止，尚未进入选择或测试。独立检查发现，两个 Base checkpoint 的 im_end 输出向量分别与其他290/266个 token 完全相同。在冻结词表、只改隐藏表示或施加共享词表仿射映射时，它们的 logits 永远相同，不能单独学会生成 im_end。该目标的 CE 下界分别为 log(291)、log(267)。原生 EOS151643 的向量则唯一。

因此本轮在新目录重新从零训练，用不含 chat 特殊 token 的补全提示和原生 EOS；旧尝试与诊断保留。不能把不适用的结束符造成的训练/生成障碍记为方法失败。这个结构约束同样影响本轮的冻结词表内部 LoRA 对照。

## 冻结与复用审计

全部 54 次训练（6烟测、18验证调参、30确认）通过原始参数逐位不变、每步冻结参数无梯度及优化器白名单检查。A-LoRA 实验没有隐藏 LoRA，内部 LoRA 对照没有边界适配器。所有 adapter 为 FP32 且从零残差开始，确认种子5002–5006。

重算 146,000 条候选预测并重新解码 32,000 条生成。近并列重算翻转 0 条；候选与生成首 token 批次形状差异 0 条。此前 475 个封存文件重新验哈希，官方 Base 权重、配置、tokenizer 逐文件核验。

模型来源见 MODEL_PROVENANCE.json，复用映射见 REUSE_AUDIT.json，选择见 SELECTION.json，完整结果见 RESULTS.json，核验见 FINAL_AUDIT.json。

## 结论范围

- 只能将本轮解释为一个选择题任务上的 Base 监督适配验证。通用指令跟随、自由长文本、多任务迁移和原能力保持尚需独立证据。
- 低参数数量不自动等于同预算竞争优势，也不意味着训练时间/显存按同比例减少；输入侧仍需穿过冻结 Transformer 反传。
- 本轮没有同时叠加边界 A-LoRA 和内部 LoRA，不能直接回答 Base 起点上的叠加收益。
- 输入含 bias、输出无 bias；输入与输出并非完全同参数预算。原始词表权重绑定不代表单侧适配后的有效计算仍然绑定。
