# SciQ 上 Base 高分及 A-LoRA 小幅收益的诊断

Base 已经过大规模预训练，已经掌握相当多知识与问答续写模式。当前结果说明 SciQ 在现有提示下对两个 Base 的适配需求有限；但较大预算内部 LoRA 仍获得更多收益，因此不能用“天花板”完整解释输入 A-LoRA 的小幅提升。

本诊断不训练任何参数，只使用两个已核验的官方 Base checkpoint。原研究封存的 700 个文件在运行前验哈希，两个原始条件与原评测预测完全一致。新诊断使用固定 998 道干净题，未加入支持段落或答案字段；删除题目、打乱题目的条件在推理前写入 DESIGN.md。属于事后描述性诊断，不是新的方法确认试验。

## 实测诊断

下表除注明外均是 A/B/C/D 四个标签中的最高分准确率。

| 条件 | Qwen3-0.6B-Base | Qwen2.5-1.5B Base |
|---|---:|---:|
| 原题目 + 原选项 | 85.07% | 89.18% |
| 原输入，全词表首 token 必须是正确字母 | 83.67% | 89.18% |
| 删除题目，保留原选项 | 40.68% | 39.18% |
| 换成另一题的题目，保留原选项 | 30.86% | 29.56% |
| 随机四选一的期望 | 25.00% | 25.00% |

原始输入下，全词表首 token 正确率仍高，说明原始高分并非主要由限定四个候选标签造成。这里不是完整自由回答准确率，也不检验后续解释是否正确。

去掉题目仍高于机会水平，说明无题目时也有可利用信号，可能涉及选项合理性、预训练先验或记忆；该实验不能区分这些来源。原始与去题目准确率相差 44.39 / 50.00 个百分点，说明模型预测明显依赖题目信息。不可把这个差值解释为推理能力的因果贡献，也不可把去题目正确率直接当作泄漏比例。打乱题目是一次固定随机置换，没有跨置换不确定性估计。

Qwen3 在删除题目时全词表首 token 正确率仅 24.25%，有效字母率 49.90%；打乱题目时分别为 23.25% / 69.34%。因此其消融条件中的四候选分数与自由首 token 分数不能混为一谈。Qwen2.5 两个消融条件的有效字母率均为 100%。

固定最常见字母仅得 25.85%，总选最长选项得 24.75%（长度并列时总选最靠前者），不能用这两种简单捷径解释高分。题目长度中位数约 12 个空格分隔词，选项长度中位数约 1 个词。比如“遗传上完全相同的个体称为什么”，选项为 adult / phenotype / male / clone；这类选择题允许模型利用已有知识识别答案，不必从适配数据重新学习该知识。

## 对涨点幅度的解释

| 方法 | Qwen3 准确率 | Qwen2.5 准确率 |
|---|---:|---:|
| Base | 85.07% | 89.18% |
| 仅输入 A-LoRA，五种子均值 | 86.65%（+1.58 pp） | 91.08%（+1.90 pp） |
| 内部 LoRA r8，五种子均值 | 89.58%（+4.51 pp） | 92.30%（+3.13 pp） |

输入 A-LoRA 约用 3.4 万 / 5.1 万参数；内部 LoRA 约用 505 万 / 923 万参数。这不是同预算性能比较，不能仅由差距判定架构优劣。不过，它确实反驳了“这个任务已无提升空间”的解释。输入 A-LoRA 的增量折算为剩余错误减少约 10.6% / 17.6%，有实际内容收益，但仍然是小幅绝对提升，不能据此宣称通用后训练能力或叠加收益。

单个边界适配器在固定主干下能改变的函数受位置、秩和参数预算约束，这是剩余差距的一种可能解释；当前实验并未分别识别这些因素，也未证明训练充分或理论能力上限。输出侧主指标未出现可靠正收益，不能把输入侧结论推广到全部 A-LoRA 放置方式。

Base 的严格“输出恰好一个正确字母”分数很低，主要涉及它会续写选项内容或解释；适配后格式合规率达到 100%。格式改善和答案选择改善应分别报告，不能把格式修正包装成同幅度知识增长。

## 预训练与比较边界

[Qwen 官方介绍](https://qwenlm.github.io/blog/qwen3/)说明，Qwen3 系列预训练数据约 36T token，包含教材、问答及知识密集的 STEM 数据。Base 可以通过预训练获得知识与问答模式，不能期待更换为 Base 后必然从很低的知识题准确率开始。

[SciQ 原论文](https://arxiv.org/abs/1707.06209)于 2017 年公开，是科学多选题数据集。无法根据当前检查确认或排除预训练接触原题；清理后训练/验证/测试之间的规范化题目精确重合为零，只排除了该有限形式的任务数据重合，不排除语义近似或预训练污染。

也不能直接将这次 Base 的分数和上一轮 Instruct 分数解释为模型阶段差异：本轮使用纯文本补全与原生 EOS，上一轮使用 ChatML/不同停止协议，尤其 Qwen3 的输入协议不同。

## 对研究设计的建议

保留 SciQ 作为单层适配可工作的基础证据；它不足以单独承担“获得新能力”或“通用后训练有效”的主论点。下一组任务应先明确要验证的适配需求，例如预训练模型未知的规则/领域标签约定，或不提供选项的答案生成；预先固定数据划分、指标、调参预算并完整报告同预算对照与较大预算参照。选择更难任务本身不会保证 A-LoRA 增益变大，不能为了增益而反复筛选测试集。
