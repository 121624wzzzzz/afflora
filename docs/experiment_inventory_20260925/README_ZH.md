“泛化”在这里指同一种适配架构在其他数据集上重新训练后是否仍有效，不是拿CLUENER/WikiSQL训练好的adapter直接零样本迁移，也不是评测预训练数据污染。

## 对照组字典

- Base：原始预训练权重，无适配器。
- H：只在Transformer内部线性层加LoRA。
- 预算H：把新增参数预算放到更多/更高rank内部LoRA；早期等参对照主要指它。
- H＋aLoRA：内部H加词嵌入E/输出U侧的隐藏维度仿射低秩适配。
- H＋普通词表LoRA：同一内部H加直接针对E/U词表矩阵的普通低秩更新；是后期更直接的边界对照。
- tied shared：同一有效E更新用于输出转置；untied的E/U独立，U-only是只加输出侧。

超过H证明叠加有用；超过预算H回答新增参数分配位置；超过H＋普通词表LoRA才回答aLoRA相对普通边界LoRA的优势。公平搜索预算≠严格等参≠双方达到全局最优。后期H配置固定，主要独立搜索边界LR。
