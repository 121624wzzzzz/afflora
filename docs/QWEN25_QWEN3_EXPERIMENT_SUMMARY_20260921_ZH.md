# Qwen2.5 / Qwen3 实验收束（2026-09-21）

## 6. 消融究竟完成了什么

九方案为 Base、H、预算H、H+E、H+U、H+E+U、E-only、U-only、E+U。E/U/E+U 中完全没有可训练内部 LoRA，所有原模型权重冻结。

- 核心九方案完整覆盖14/16块；缺口为 Qwen2.5-1.5B/3B 的 WikiSQL 部分单侧和独立边界种子。
- Qwen2.5-7B、Qwen3-8B 两个 untied 型号在两项核心任务上的三种子九方案均完整。
- 额外的 untied 五种子全架构块0/4完整；不能声称五种子单侧消融已齐。
- 双侧并不统一最佳：0.5B WikiSQL 的 H+E 高于双侧；Qwen3-0.6B/4B CLUENER 的 H+U 高于双侧；8B WikiSQL 的 H+U 与双侧均值相同。
- E/U的bias、容量等并不完全相同，这些是实际方案消融，不是只改变位置、其余完全匹配的纯机制对照。

独立边界适配的例子：

|任务 / 模型|Base|E-only|U-only|E+U|双侧参数|
|---|---:|---:|---:|---:|---:|
|CLUENER / Qwen2.5-1.5B|0.000|36.052|30.904|45.657|99,840|
|WikiSQL / Qwen2.5-7B|50.293|62.858|51.400|70.443|232,960|
|WikiSQL / Qwen3-8B|46.582|60.710|60.417|67.708|266,240|

三种子均值。8B WikiSQL 独立双侧相对Base +21.126pp，校正区间[19.195,23.057]；但仍低于内部LoRA，且该矩阵没有同预算的standalone内部LoRA对照。U-only也有失败案例：Qwen3-0.6B WikiSQL 3.776%，低于Base 5.371%。

## 7. 早期实验如何保留

- **CE与生成分开**：修正后的 Qwen3-0.6B Base / Qwen2.5-7B Base，rank8/32/64 × 三种子，18/18配对单元的叠加CE均优于普通和预算对照；IFEval相对预算的六个条件均值却五负一平。[修正对照](../reviewer_followup/stacking_gain_corrected_20260914/FINAL_INTERPRETATION_ZH.md)
- **聊天模型 SciQ 叠加**：有独立学习率选择、内部仿射位置对照和五种子确认，未建立稳定额外准确率优势。[位置对照](../reviewer_followup/stacking_sciq_placement_20260915/FINAL_INTERPRETATION_ZH.md)
- **Base SciQ 单侧**：修复评分后，E-only 候选准确率相对Base：Qwen3-0.6B +1.583pp，Qwen2.5-1.5B +1.904pp。扩至16个主比较后，前者校正种子区间正，后者跨零。相对小预算内部LoRA，Qwen3无优势证据；Qwen2.5 +1.563pp通过该效率比较族，但双方并非严格等参（50,688 vs 49,152）。旧报告被修复版统计口径限定，不沿用已过期的更强表述。[修复报告](../reviewer_followup/sciq_repaired_protocol_20260916/FINAL_INTERPRETATION_ZH.md)
- **CMRC任务内SFT、CMRC/C3迁移**：小幅正向或混合结果，未建立两个模型相对两个对照均稳定受益；不得与Base核心任务合并。[CMRC任务适配](../reviewer_followup/stacking_cmrc_task_sft_20260915/FINAL_INTERPRETATION_ZH.md)、[中文迁移](../reviewer_followup/stacking_chinese_transfer_20260915/FINAL_INTERPRETATION_ZH.md)
- **评分正确性诊断**：核对Base/Instruct身份、原生BOS/EOS、统一生成长度、格式与内容分别计分、标签候选与实际生成、内容/EOS loss分解、官方任务评分、原权重冻结、共同初始化/顺序、预算和保存重载。[CE/内容分解](../reviewer_followup/stacking_eval_decomposition_20260915/FINAL_INTERPRETATION_ZH.md)

## 8. 收束后的证据组织

主线可写为：在所测Qwen2.5/Qwen3的小数据实体抽取和查询语义解析设置中，边界aLoRA在很小新增参数预算下，为内部LoRA提供了方向一致的增量；若干五种子条件同时通过相对普通和预算对照的预定校正区间。边界模块也能在冻结内部层时独立适配任务，但单侧/双侧及其他任务的收益具有条件性。

主文优先呈现两个核心任务、八型号覆盖和三个较强五种子条件；独立E/U适配与untied消融支持架构讨论；工具调用/Banking77/E2E作为补充正向证据。TREC50、SQuAD2、ANLI、SciQ/IFEval等不稳定或负向结果保留作适用边界。不能按正负筛掉任务后声称普遍有效。

14小时扩展的工作量为377次新正式训练、18项Base、32次短程检查，另复用104条经过核验的历史运行记录。它不是377个独立模型/任务条件，复用记录也不是新重复。125个计划运行未通过完成状态，不计入完成量。不同阶段共享数据与种子、三/五种子嵌套，因此本页不把各阶段运行数相加当作独立证据总量。

未解决的主要问题是：多数Qwen主线尚缺独立且对称的超参数搜索，部分架构块缺种子，公开数据预训练暴露未知，少量种子与选定任务限制外推。已有正结果应按具体条件保留，不能因扩展矩阵的大比较族跨零而抹去，也不能把各轮显著结果合并成覆盖所有选择的确认性结论。
